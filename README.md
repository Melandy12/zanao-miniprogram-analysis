## 三、技术要点速览

- 业务接口：`https://api.x.zanao.com`；分享/H5：`https://c.zanao.com/sc-api/...`；图片 CDN：`b1/b2.cdn.zanao.com`（直链无鉴权）。
- 签名参数 `_ut_`：`AES(随机串(20) + "$##$" + userToken + "$##$" + 时间戳)`，AES KEY/IV 为前端包内混淆常量。
- 真正的访问限制是 **userToken**：只能由 `wx.login` + 校园身份认证换取，认证为人工审核；因此只能以当前已认证账号可见的学校/校区身份取数。
- 解包解密（PC 微信 4.x，`V1MMWX` 头）、接口清单与字段细节见 `探测/README.md`。
